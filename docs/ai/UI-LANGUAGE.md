# 화면 언어 전환 · 2026-09-21

## 범위와 동작

- 한국어·영어·중국어 간체·일본어를 사이드 메뉴에서 선택한다. 데이터·AI·웹캠 등 별도 화면에도 언어 선택을 제공한다.
- 메뉴, 설명, 점수·근거 안내, 상태·오류, 폼 도움말, 날짜 표시를 선택 언어로 갱신한다. 화면을 다시 마운트하지 않아 선택 장소, 열린 상세 설명, 입력 중인 내용이 유지된다.
- 선택은 `pongdang.travel-language`에 저장하고 탭 간 변경을 구독한다. 잘못된 저장 값은 한국어로 처리하며 저장소가 차단되어도 현재 탭에서 전환된다.
- 새 추천·대화 요청에 선택한 locale을 전달한다. 다른 언어로 만든 추천 토큰을 재사용하지 않는다. 외국어 제공처 조회에서는 기존 기본 검색어 `강릉`만 제거하고 명시적인 다른 지역·장소 ID는 보존한다.
- 제공처 장소명·주소·원본 자료, 사용자가 입력한 내용, 기존 대화·코스는 원문을 유지한다. 수집 자료가 없을 때 번역된 가짜 자료를 만들지 않는다.

## 통합과 제약

- 기준 main: `a047dceb24c7403e0552590d05c29ed72c4698e0`. 최신 전체 화면 지도·내 코스, 새 로고·파비콘·하단 물결을 유지하고 새 화면 문구에도 번역을 연결했다.
- 강원도 수집 범위 확장·지역 필터·DB 마이그레이션은 별도 로컬 작업으로 보존하고 이번 언어 변경 커밋에는 포함하지 않는다.
- 백엔드 실행 코드는 변경하지 않는다. `browser_contract_server.py`에만 언어별 제공처를 검증하는 격리 테스트 자료를 추가했다.
- 의존성·운영 환경·SSO·인증·스키마 변경 없음. 배포는 dev CI 통과 후 동일 커밋의 main CI 및 기존 자동 배포 흐름을 따른다.

## 검증

- Node 24: frontend lint, 단위 테스트 111개, 타입 검사 및 production build 통과.
- Python 3.14 / 별도 PostgreSQL 18 `pongdang_test`: Ruff check·format, backend 1,170개 통과. Docker가 없는 로컬 환경의 Compose 검사 2개는 skip이며 CI smoke에서 검사한다.
- 전체 Playwright 브라우저 134개가 통과했다. 모바일·데스크톱 언어 전환, 실제 제공처 선택, 상태·입력 보존, 재진입·새로고침 지속성, 차단된 저장소 처리를 포함한다.
- `frontend/tests/i18n.test.mjs`는 세 언어 사전의 값 치환 계약과 제공처 원문 보존, 기존 재시도 오류의 언어 갱신을 검증한다.
- 운영 배포 여부는 해당 커밋의 GitHub Actions `CI and deploy` 결과와 배포 로그를 기준으로 확인한다.

## 강원도 범위 통합 · 2026-09-21

- 강원도 확대 후 새 요청은 기본 `gangwon` 범위와 명시적으로 선택한 시군을 언어가 달라져도 유지한다. 백엔드가 지역 코드와 각 언어의 별칭을 처리하므로 외국어 전환 시 강릉 검색어를 제거하던 이전 보정은 사용하지 않는다.
- 지도·내 코스의 전체 화면 배치와 로고·파비콘·푸터, UI 언어 선택 및 입력 보존은 그대로 유지한다. 확장 상세는 [GANGWON-EXPANSION.md](GANGWON-EXPANSION.md)에 기록한다.
