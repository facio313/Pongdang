# 물 여행 적합도 지수 근거 연구 프로토콜

## 범위와 사전 기록

프로토콜 v1을 2026-09-14 01:33 KST에 작성했다. 문헌 검색 시작 전 계획이며, 저장소 지침과 지정 프론트엔드·수집 계약을 먼저 읽었다. 검색 종료일은 2026-09-14 KST이다. 발행 연도의 하한은 두지 않고 종료일 이전 자료를 대상으로 한다. 최신 논문뿐 아니라 지수의 최초 개발·검증 연구를 추적한다. 이번 산출물은 제한된 검색원에서 수행하는 구조화된 근거 종합이며, 전 학술 데이터베이스를 망라한 체계적 문헌고찰 또는 정식 GRADE 평가라고 부르지 않는다.

변경은 이 연구 문서 디렉터리에 한정한다. 제품 코드, 프론트엔드, DB, 배포, 자격증명은 변경·실행하지 않는다. Multtara는 읽기 전용 참고 자료다. Pongdang은 feature/api, HEAD d07cd23279808e74c1998d849c240a48e06d06d2에서 시작했으며, 다수의 기존 미커밋 변경을 포함한다. 시작 상태와 기존 파일 SHA-256은 `working/baseline.json`에 기록한다. 감사는 HEAD만이 아니라 **현재 작업 트리**를 기준으로 하며, 원격 다른 브랜치를 확인한 것으로 간주하지 않는다.

현재 확인한 WaterForecastPage 및 WaterIndexHubPage는 적합도 계산·추천 순위가 미구현임을 명시한다. swim, surf, relax, mudflat, onsen, rafting은 legacy에서 검증할 후보 분류이지, Pongdang의 확정된 여섯 제품 기능이 아니다. 실제 지원 계약은 저장소 감사에서 확정한다.

## 연구 질문

1. 활동별 환경 노출은 A(주관적/열적 쾌적성·만족), B1(진술 선호·참여 의향), B2(관측된 선택·참여), C(활동 가능 조건·안전 제한)와 어떻게 연결되는가?
2. 해변 관광 지수 HCI:Beach의 개발·검증 모집단·시간 집계·결과변수는 무엇이며, 입수/서핑/휴식 및 한국의 시간대 추천에 전이 가능한가?
3. 기온·습도·체감/열지수의 공통 정보, 육상과 입수 중 열수지의 차이, 강수확률·양·지속시간의 차이는 기존 규칙에서 보존되는가?
4. 바람·수온·일사/구름·파랑·조석/유속·수질 중 어떤 변수가 활동별로 필요하며, 현재 수집 계약이 그 정의와 시공간 해상도를 제공하는가?
5. 장소·계절·기후·연령·장비·숙련·노출시간 및 적응 차이 때문에 어떤 외삽이 제한되는가? 상반되는 연구는 무엇인가?
6. 서로 다른 활동 점수의 공통 척도와 실제 활동 선택을 검증한 근거가 있는가? 유지·수정·폐기·보류할 legacy 규칙은 무엇인가?

## 검색원과 접근 범위

사용 가능한 도구를 확인했다: web 검색/페이지 열람, 연결된 Exa 웹 검색·본문 추출, 로컬 파일·Git 읽기. Exa Search 및 Deep Research 스킬을 읽었다. 검색은 이 두 웹 검색 도구를 사용하고, 발견한 출판사 원문·PubMed/PMC·기관 리포지터리·국내 학술 사이트·공식 기관 자료를 직접 연다. Scopus, Web of Science, Embase, KCI/RISS/DBpia 등의 독립 데이터베이스 검색을 실행하지 않으면 검색했다고 보고하지 않는다. 검색엔진의 `site:` 쿼리는 해당 데이터베이스의 직접 검색과 구별한다. 로그인·유료벽·봇 차단은 접근 실패로 기록한다. 추가 플러그인 설치는 필요 조건으로 삼지 않는다.

## 포함·제외와 단계별 집계

포함: 환경 요인과 해당 활동의 명시된 결과 사이의 관계를 측정한 동료심사 원자료 연구, 지수 원개발/검증 논문, 관련 체계적 리뷰(원연구 추적용), 관할이 확인된 공식 안전·통제 지침. 한국 자료를 우선하되 해외 근거도 별도 표시한다. 원문 접근 불가 자료도 관련성이 높으면 초록 범위의 제한된 근거로 남긴다.

제외: 여행 홍보·근거 없는 블로그, 환경 노출 또는 결과변수가 무관한 논문, 같은 논문의 단순 재게시, 검증 불가능한 수치, 질환 치료 효과만 평가하여 활동 조건으로 전이할 수 없는 온천 연구. 공식 안전 자료는 선호 효과의 증거로 사용하지 않는다. 리뷰의 핵심 수치를 원연구 확인 없이 점수 경계로 사용하지 않는다.

한 `search_log.csv` 행은 검색에 반환되어 실제 보존된 하나의 결과 또는 직접 열람 시도다. 검색의 추정 전체 히트 수는 기록하지 않는다. `returned_count`는 같은 검색 묶음에 반복될 수 있으므로 합산하지 않는다. 검색 레코드 수, 고유 연구 수, 초록 확인 수, 원문 확인 수를 따로 집계한다. 검색 스니펫은 초록 확인으로 세지 않는다. 동일 DOI·제목·저자·연도 중복을 묶고, 같은 표본/관측자료 재사용은 `sample_family`로 표시한다. 원문은 관련 방법·결과·한계 부분을 실제 열람한 경우에만 `full_text_checked`로 분류한다.

## 추출과 근거 강도

추출 단위는 `활동 × 요인 × 결과변수` 주장이다. `evidence_matrix.csv` 필드: evidence_id, study_id, sample_family, source_type, title, authors, year, doi, url, design, country_climate, season, population, sample_size, activity, outcome_domain, comparison, input_definition_unit_aggregation, outcome_measure, finding_effect_uncertainty, condition_range, location_in_source, confounders_bias, applicability_limits, korea_directness, access_status, evidence_strength, strength_rationale, code_implication, conversion_note, search_ids.

미보고 또는 미확인 값은 `NR`/`미확인`으로 남기며 0으로 채우지 않는다. 효과의 방향과 효과크기·불확실성을 구분한다. `conversion_note`에 원문 그대로인지, 재계산/단위 변환인지 명시한다. 원문에 없는 표본 수·임계값·효과를 만들지 않는다. 성인 근거를 아동·고령자에게 자동 적용하지 않는다.

출처 유형(`empirical_peer_reviewed`, `index_development`, `review`, `official_guidance`, `service_design_assumption`, `legacy_unvalidated`)과 주장별 강도를 분리한다. 자체 강도는 `중간`, `낮음`, `매우 낮음`, `정책 권위/효과 근거 아님`으로 평가한다. 설계, 표본 선택, 교란, 불확실성, 결과 일치, 한국 직접성을 정성적으로 설명한다. 이 등급은 GRADE나 공인 인증이 아니다. 코드는 `legacy_audit.md`에서 미검증 값으로 관리한다.

## 종합과 메타분석 판단

활동별 A/B1/B2/C, 직접/간접 근거, 일치/상충/공백 표를 만든다. 보편적 최적 온도를 평균하지 않는다. 메타분석은 같은 활동·비슷한 모집단·노출 대비·결과 정의·집계 시간 및 재현 가능한 효과크기와 표준오차가 갖춰진 독립 표본의 하위 묶음에 한해 검토한다. 조건이 충족되지 않으면 수치 결합을 하지 않고 불충족 항목을 기록한다. 수행할 경우 코드, 효과 계산, 중복 표본 제외, 이질성 및 민감도 분석이 필수다.

코드별 판단: 유지=근거가 지지하는 구조/정의, 수정=구조는 유용하나 모집단·척도·변수 정의 수정 필요, 폐기=개념 혼동/검증 없이 안전·활동 간 우열을 생성, 보류=수치화를 지지할 직접 자료 부족. 안전 통제와 쾌적성은 별도 체계로 두고 모름/노후/활동 미지원은 좋은 점수로 대체하지 않는다.

## 종료 기준 및 수행 한계

각 후보 활동을 검색하고, HCI 원개발·검증 및 독립 대안 영역을 확인하며, 핵심 주장에 원문 위치 또는 접근 한계가 연결되면 종료할 수 있다. 마지막 보완 검색에서 핵심 판단을 바꿀 새로운 직접 근거가 없고 남은 공백을 구체적 조사로 표현할 수 있어야 한다. 문헌 개수 목표는 없다. 전 세계 근거의 포화를 주장하지 않는다. 업무를 나눈 보조 에이전트의 추출을 총괄 검토하지만, 독립 이중 선별/추출이나 사전등록을 수행했다고 주장하지 않는다.

## 실제 수행과 검색 종료

최종 검색/서지 보완은 2026-09-14 KST에 종료했다. 여섯 후보 활동에 대해 개별 결과영역을 찾고 HCI 원개발·검증과 독립 입수/수질/서핑/유량 연구를 확인했다. 마지막 보완은 웹캠 방문(B2)과 진술 선호의 차이, hot tub 공식 상한의 대상 범위를 명확히 했으며 공통0–100 척도를 새로 검증하지 않았다. 해당 근거를 추출한 후 추가 광범위 검색을 종료했다. 각 활동에 A/B/C의 모든 직접 근거를 얻었다는 의미는 아니다. 특히 갯벌 선호, 한국 시간별 개별 활동 선택, 아동/고령자 수치 모델은 공백이다.

종료 기준 중 ‘핵심 판단을 바꾸는 새로운 직접 근거가 없는 마지막 보완’을 이 제한된 검색 범위에서 적용했다. 남아 있는 미검토 관련 후보는 `not_extracted_candidate`/`not_prioritized`로 기록했다. **이 후보들이 무관해서 제외되었다거나, 모든 초록을 검토하여 배제되었다고 간주하지 않는다.** 검색 포화와 전 세계 근거의 부재를 주장하지 않는다. 추가 접근권/현지 자료가 생기면 본 종합을 갱신해야 한다.

`ac-search1`은 네 검색식을 한 호출에 묶었다. 도구가 반환 결과의 개별 검색식 출처를 구분하지 않은 경우 각각에 임의 배정하지 않고 네 식을 함께 기록했다. 반환 레코드의 고유 URL은758개지만, 서로 다른 URL에 같은 DOI/표본이 있을 수 있으므로 연구 수가 아니다. 열람·페이지 탐색·재시도95건과 Crossref 서지조회14건을 합친 로그는909행이다. `returned_count`는 묶음별 반복 표시 값이므로 행마다 더하지 않는다.

최종 선정 출처36개/주장47개: 동료심사 원자료20, 지수개발7, 리뷰1, 학회 초록1, 공식 모니터링1, 공식 안내6. 원자료/지수개발27편 가운데 관련 방법·결과 원문 확인13편, 초록 한정14편이다. 여기에 리뷰 원문1편·공식 자료 원문7개·학회 초록1개를 별도 더하면 원문21/초록한정15가 된다. 단순 스니펫을 초록 확인으로 세지 않았다. 전체800건의 독립 초록 선별 수나 원문 제외 수를 역산한 PRISMA 흐름도를 만들지 않았다.

실제 사용: web 검색·open/find/click/PDF screenshot, Exa 검색·본문 추출, 공개 출판사/기관 PDF의 일반 HTTP 재시도, Crossref 공개 API 서지 조회, 로컬 Git·파일 읽기. 웹 오류429/403/401·CAPTCHA·구독벽과 대체 경로의 성공/실패는 각 로그에 남겼다. 기관 PDF는 필요한 페이지의 렌더도 확인했다. 유료 계정·구독 데이터베이스·인증 우회는 사용하지 않았다. Hutt2001, WHO2006 등 서지 추적용 자료는 Bib에 별도 메모를 두고 주장 수에서 제외했다.

## 로그·근거표 읽는 방법과 QA

- `record_type=search_return`은 보존한 검색 결과 한 항목이다. `retrieval_attempt`는 원문/초록/메타데이터·페이지 조작을 포함한 접근 기록으로, 성공한 논문 수와 다르다. `metadata_lookup`는 Crossref 조회다.
- `decision`은 반환 단계의 검토 결정을 기록한다. `linked_to_included_study`, `selected_study_record`는 같은 연구의 인덱스 사본일 수 있다. `access_attempt`/`access_failed`는 접근 상태와 함께 읽는다. `handoff`는 담당 전달이며 원문 확인 표시가 아니다. 최종 포함 여부·최고 접근 수준은 `study_id`로 근거표와 연결해 확인한다.
- `raw_record`는 실제 검색에서 나온 제목/URL/식/ID를 담은 메타데이터 파일의 위치다. 문헌 전문이나 전체 검색엔진 응답을 재배포하는 파일이 아니다. 정리 후에도 반환 순서·중복과 선정/제외 이유를 보존한다.
- 원문 문장을 길게 복사하지 않고 주장·수치를 요약했다. `NR`은 미보고/미확인이고0이 아니다. `conversion_note`는 원문값과 재계산 여부를 구분한다. cfs와 m³/s를 억지로 통일하거나 불명 단위를 추정하지 않았다.
- HC17은 미기후 대리지표, AC01은 수행부하, AC02는 정보 조회 수요로 표시했다. 이런 보조 결과를 A/B/C의 직접 측정으로 높여 해석하지 않는다. 공식 지침의 권위는 실험적 효과크기의 강도와 별개다.
- sample_family에는 Caribbean472명 중복 가능성, Guéritée 연구 프로그램 중복 미확인, 동일Dolores/Vandas 자료, 동일SanDiego코호트, 반복 서핑세션/입욕조건을 기록했다. 같은 연구의 여러 주장을 독립 연구로 합산하지 않는다.
- 통계적 결합이 부적절하여 메타분석을 수행하지 않았다. 독립 대비·분산·시간창을 확보하면 하위 묶음부터 검토한다. 현재 재현 스크립트는 산출물 합성·ID/열/서지/검색 연결 검사에 한정한다.
- 보조 에이전트는 영역별 검색/추출 및 최종 산출물 QA를 수행했고 총괄이 통합했다. 이것은 독립 이중 문헌 선별이나 사전등록 프로토콜 준수 인증이 아니다. 파일 보존·참조 검증 결과는 `working/validation.json`에 기록한다.
