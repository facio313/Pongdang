# KR01 보완 근거 메모

KR-S01은 김진동·허중욱(2019), 관광연구저널33(5):165–181, DOI10.21298/IJTHR.2019.5.33.5.165다. [저널 원제공 DBpia 초록](https://www.dbpia.co.kr/journal/articleDetail?nodeId=NODE08743987)과 KCI 상세에서 서지·국영문 초록을 확인했다. 웹 검색2개(반환16레코드), 직접 열람/접근경로5개를 보존했고 중복 후 연구1개, 초록검토 연구1개, 전문검토0개다. KCI/RISS/DBpia 독립 검색은 하지 않았다. DOI 웹 도구 오류 후 공개 HTTP는 DBpia로 정상 연결되었으므로 DOI가 유효하지 않다고 보고하면 안 된다. DBpia 전문은 구독확인 안내가 있고 확보하지 못했다.

해당 연구의 결과는 B2 해변 피서객 집계다. 초록은 11년 동안 날씨와 피서객의 변동이 단순한 비례관계로 일관되지 않았다고 보고한다. 사람수/독립 관측 N·조사 시작종료연도·변수별 통계량·조정모형은 미확인이다. 따라서 한국 기온 또는 습도가 수영선호에 미치는 수치효과를 제공하지 않는다. 관광패턴·접근성·시설·사회경제 변화가 함께 고려되어야 한다는 현장검증 설계의 제한적 맥락으로 사용한다(KR01). 이 근거 자체로 환경요소의 효과가 없다고 결론내릴 수도 없다.

다른 연구와의 동일 표본/자료 재사용은 확인할 수 없었다. 동일 DOI의 KCI/RISS/DBpia/ResearchGate 반환은 단일 연구로 묶었다. 원문 확보 뒤 확인할 항목은 방문수 산정·개장일/휴일·연도추세·기상 집계창·효과 불확실성·개별 물활동 식별 여부다. 비교 가능한 효과·분산이 없으므로 메타분석 결합 대상이 아니다.
