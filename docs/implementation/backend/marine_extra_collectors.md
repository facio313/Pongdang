# 추가 해양 API 자동 수집 연결

확인일: 2026-09-14. 이 문서는 신규 어댑터의 명세 검증과 구현 범위를 설명한다.
실제 인증키 호출·DB 저장 결과는 전체 연결 검증 보고서에 별도로 기록한다.

| 신청 ID | 작업 이름 | 수집 범위 | 원래 단위·해석 | 공식 근거 |
|---|---|---|---|---|
| MAR-10 | `khoa_tide_timeseries` | 설정한 조위 예보지점, 오늘부터 7일, 60분 간격 | `tdlvHgt`: cm. 지점 기준면을 해발고도로 바꾸지 않음 | [공식 Swagger·활용가이드](https://www.data.go.kr/data/15156022/openapi.do) |
| MAR-11 | `khoa_hf_current` | 설정한 HF 관측망의 최신 관측시각을 확인하고 동일 시각의 격자를 페이지 조회 | `crsp`: cm/s, `crdir`: degree. 각 격자의 실제 좌표 보존 | [공식 Swagger·활용가이드](https://www.data.go.kr/data/15155531/openapi.do) |
| MAR-12 | `khoa_current_timeseries` | 설정한 조류 예보지점, 오늘부터 7일, 60분 간격 | `crsp`: cm/s, `crdir`: 16방위 문자열. 실제 응답의 `동` 등을 각도로 임의 변환하지 않음 | [공식 Swagger·활용가이드](https://www.data.go.kr/data/15156024/openapi.do) |
| MAR-14 | `khoa_roms` | 수집 중심의 최대 0.1° × 0.1° 사각형과 API가 반환한 예측시각 | `crdir`: degree, `crsp`: m/s, `wtem`: °C. Swagger에 생략된 단위는 공식 HWP 응답명세로 확인 | [공식 Swagger·활용가이드](https://www.data.go.kr/data/15142227/openapi.do) |

`marine_extra_jobs(settings)`가 기존 독립 수집 worker에 전달할 네 `Job`을 반환한다.
HF는 1시간 주기이고 다른 세 작업은 6시간 주기다. 공공데이터포털 키가 없으면 비활성화된다.
추가 설정은 `khoa_current_station_code`와 `khoa_current_forecast_code`이며,
조위 지점은 기존 `khoa_tide_station_code`를 사용한다.

군산항 `HF_0076`과 비진도남측 `16LTC10`은 수신 검증에 사용된 기관 지점이다.
이 지점들의 자료가 경포를 대표한다고 처리하지 않는다. HF 관측망은 한 번의 응답에
서로 다른 좌표의 격자가 여러 개 포함되므로, 관측망 코드와 실제 좌표를 함께 사용한
`derived:` 식별자로 보관한다. ROMS도 실제 예측 격자와 시각을 기준으로 식별한다.

한 요청은 최대 100행이고, 한 작업은 최대 51회 요청·5,000행이다.
HF의 추가 1회는 최신 시각 확인이다. 5,000행을 넘어가는 응답은 `coverage=bounded`로
표시하며, 제한된 ROMS 영역을 전체 수집 반경이나 전국 수집으로 표시하지 않는다.
페이지 전체 건수가 도중에 바뀌거나 페이지가 반복·누락되면 성공으로 저장하지 않는다.
HF는 첫 조회가 반환한 실제 `obsrvnDt`를 후속 요청의 `yyyyMMddHH`에 고정하여
갱신 도중 서로 다른 시각의 격자를 섞지 않는다.

ROMS는 요청 경계를 소수점 다섯 자리로 정규화한다. 최솟값을 올리고 최댓값을 내려서
원래 조회 영역을 넓히지 않는다. 2026-09-14 실제 소량 조회에서
`ymin=37.75341`, `ymax=37.85340`, `xmin=128.86022`, `xmax=128.96021`은
정상 응답과 전체 1,602건을 확인했다. 같은 영역의 소수점 여섯 자리 요청과 긴
부동소수점 문자열 요청은 `10 / INVALID_REQUEST_PARAMETER_ERROR`였다.
이는 해당 요청의 실제 호환성 검증 결과이며, 공식 명세에 없는 전역 자릿수 제한으로
일반화하지 않는다. 응답에 포함된 실제 격자 좌표는 반올림하지 않고 보존한다.

기존 KHOA 어댑터와 동일하게 시각을 KST로 해석한다. 예측자료에는 발표시각이 없으므로
`issued_at=null`을 보존한다. API가 별도 만료를 제공하지 않으므로 저장 유효구간은
관측·예측 대상시각부터 1시간으로 제한한다. 이를 공식 운영시간이나 입수 가능 시간으로
사용하지 않는다. 재수집은 원래 대상시각·유효구간을 늘리지 않는다.

예측은 `forecast`, HF 실측은 `observation`으로 분리한다. 결측·원문 숫자/문자열·지점
좌표·정정 식별자를 보존하며, 기존 `SourceBatch` 원자적 저장 경로를 사용한다.
어댑터는 점수·안전 상태·활동 지원 근거를 생성하지 않는다.

자체 확인: `tests/test_marine_extra.py` 35건 통과, 두 파일 Ruff 검사·포맷 통과.
테스트 자료는 파서·경계 조건을 검증하기 위한 고정 입력이며, 운영 DB에 넣지 않는다.
