# Pongdang 데이터 확보·API 신청표

> 2026-09-14 후속 반영: 신청 이후 자동수집 15종을 연결했다. 14종은 실제 자료 저장, 자동수질 1종은 정상 빈 응답, 번체 관광·수문 방류 2종은 승인 확인 대기다. 최신 결과는 [자동수집 연결 결과](api-connection-2026-09-14.md)를 기준으로 본다. 아래 신청 표는 신청 당시 안내를 보존한 것이다.


작성·공식 안내 확인: 2026-09-14 KST.

후속 확인: 사용자가 KMA-07을 제외하고 신청한 뒤, 2026-09-14 12:36~12:38 KST에 실제 API를 재검사했다. 신규 대상16종 중 자료 수신13종, 인증 정상·자료0건1종(WQ-04), 인증 거절2종(HYD-03·TOUR-05)이다. [신청 후 4차 검증](api-recheck4-2026-09-14.md)을 최신 수신 상태로 사용한다. 아래 신청 방법·제공자료 설명과 이전 실패 이력은 보존한다.

여섯 활동(수영·서핑·휴식·갯벌·온천·래프팅)에 필요한 데이터를 어디서 신청하고 어떤 조건으로 조회할지 정리했다. 신청 우선순위는 Pongdang 구현 목적에 따른 제안이다. API 이용승인과 앱 수집 연결 완료는 각각 확인한다.

현재 사용자 계정의 승인 화면은 열지 않았다. 아래 기존 16종의 `HTTP 403 / 코드 30`은 [9월 14일 00:00 KST까지의 실호출 기록](api-recheck3-2026-09-14.md)이다. 이번에는 공식 공개 설명과 현재 코드를 검토했으며 인증키를 이용한 재호출·활용신청·설정 변경은 하지 않았다. 미신청이면 신청하고, 이미 신청했다면 승인·사용기간·사용 중인 서비스키 연결을 확인한다.

개발 자동승인은 운영 자동승인을 뜻하지 않는다. 위 KHOA 4종, AirKorea 2종, 관광 5종은 공식 페이지상 운영 심의승인이다. KMA-04·ASTRO-01·WQ-04는 개발·운영 자동승인, HYD-03·KMA-07은 개발·운영 심의승인이다. 추가 수질 정점조회 API는 개발 자동·운영 심의다. 호출량은 서비스별 승인 화면에 표시되는 한도를 적용한다.

| 갯벌 운영시간·귀환 경로 | 체험장·어촌계·지자체 | 공식 운영창·예약 공지·동선 지도 요청. 조위관측소와 경로의 관계 검수. 고저조 시각만으로 운영창을 생성하지 않음 |
| 라이브캠 | 지자체·공공기관·시설의 공식 영상 운영 주체 | 공개 영상 페이지·재생 주소·임베드/재사용 허가·촬영 지점 확보 후 허용 호스트 검수와 실제 생중계 확인 |
| 장소별 대표 관측소 | 해당 관측기관의 위치·지점 자료와 장소 관리 주체의 근거 | 장소·관측소 좌표와 관측 범위·활동·유효기간 검토. 검수한 매핑으로 등록하며 최근접 지점을 자동 대표값으로 사용하지 않음 |

## 신청하는 순서와 입력 예시

1. 표의 공식 페이지에 로그인해 **활용신청 → 개발계정 신청**을 진행한다. 이미 신청한 서비스는 신규 신청 대신 승인·기간·연결된 키를 확인한다.
2. 활용용도는 실제 개발 형태에 맞게 웹 개발/앱 개발을 선택하고, 서비스명은 `Pongdang(퐁당)`으로 기입한다. 아래 활용목적은 초안이며 사실과 맞게 수정해 사용한다.
3. **마이페이지 → 오픈API의 신청 내역**에서 승인 여부·사용기간·일일 호출한도·해당 서비스의 인증키를 확인한다. 메뉴 명칭은 포털 개편에 따라 일부 다를 수 있다.
4. 심의 항목은 제공기관의 승인을 확인한 후 호출한다. 운영 공개·호출량 확대 때에는 해당 서비스의 운영계정 절차를 별도로 확인한다.
5. 이후 개발에서 승인된 명세의 실제 관측소·지역·날짜로 작은 표본을 조회하고, 수신 값·단위·시각·자료 범위를 확인한 뒤 자동 수집에 연결한다.

절차 근거: [공공데이터포털 활용가이드](https://www.data.go.kr/ugs/selectPublicDataUseGuideMetView.do), [공정거래위원회 공식 OpenAPI 신청 안내](https://www.fairdata.go.kr/ext/data/openApiGuidance.do). 서비스별 심의·형식은 각 행의 공식 상세 페이지가 기준이다.

활용목적 입력 초안:

> 수영·서핑·해변 휴식·갯벌 체험·온천·래프팅 장소의 환경정보를 제공하는 Pongdang 웹 서비스를 개발합니다. 공공데이터를 장소 및 시각별로 조회하여 기상·해양·수질·하천·관광 정보를 출처와 함께 표시하고, 이용자가 선택한 조건의 비교에 활용합니다. 관측·예보·결측과 자료의 적용 범위를 구분하여 제공합니다.

## 승인 후 백엔드 연결

| 단계 | 할 일 |
|---|---|
| 사용자가 확인 | 신청한 서비스명/ID, 승인 상태, 사용기간, 호출한도. 키 값은 공개 문서나 채팅에 적지 않고 기존 비공개 서버 설정으로 관리 |
| 서버 인증 설정 | 기존 공공데이터포털 계열은 `DATA_GO_KR_KEY`, API허브는 `KMA_API_HUB_KEY`, HRFCO는 `HRFCO_KEY`, Kakao REST는 `KAKAO_REST_KEY`. 새 키가 서비스별로 다른 경우 현재 단일 키 설정의 확장부터 검토 |
| 수집 구현 | 승인된 공식 HTTPS API를 worker에서 조회 → `SourceBatch` 정규화 → 독립 `pongdang_data`에 출처·시간·단위·수정본 보존 |
| 화면 연결 | 저장자료를 실제 `/api/data`로 읽고 조건·근거표에 연결. 필요하면 새 지표의 API/프론트 계약 확장 |
| 완료 확인 | 제공처 실제 수신, 저장, 최신성·단위·지점 적용, 화면 조회를 확인. 미확보 값은 보류하며 승인만으로 점수 모델 검증 완료 처리하지 않음 |

이 문서는 신청 준비 자료다. 사용자 대신 신청하거나 승인됐다고 표시하지 않았으며, 기존 키 파일·환경설정·수집기·운영 DB를 변경하지 않았다.
