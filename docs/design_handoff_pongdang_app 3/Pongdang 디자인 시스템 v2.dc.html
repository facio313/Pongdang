Pongdang · Design System v2

물안개 파스텔 × 코발트 글래스

두 스타일을 한 시스템으로 합쳤습니다. 코발트 글래스는 「지금·여기」를 보여주는 히어로 레이어, 물안개 파스텔은 읽고 고르고 입력하는 본문 레이어입니다. 한 화면에 글래스 히어로는 하나까지, 근거·표·폼은 항상 밝은 본문 레이어에 둡니다.

01 — 두 레이어의 역할

Hero layer · Cobalt Glass
오늘의 상태 · 지도 · 라이브캠
  • 화면 최상단 1개. 스크롤해도 아래로 반복하지 않습니다
  • 내부 카드는 유리면 rgba(255,255,255,.14) + 흰 헤어라인
  • 숫자는 Space Grotesk 700, 40px 이상
  • 본문 길이 텍스트는 두지 않습니다(대비 관리 비용)
Body layer · Mist Pastel
취향 선택 · 근거 · 목록 · 폼
  • 배경 #eef4fb 위 흰 카드, 라운드 18
  • 그림자는 0 6px 20px rgba(20,44,72,.10) 한 단계만
  • 13px 이상 본문, 캡션 11px, 터치 타깃 44px
  • 데이터 상태·근거 표기는 전부 이 레이어에서

03 — 등급 팔레트 (레이어별 2세트, 순서 동일)

밝은 레이어 · 파스텔 필 + 진한 글자 + 등급 아이콘
80+ 매우 좋음 60+ 양호 40+ 보통 20+ 주의 나쁨 – 평가값 없음
글래스 레이어 · 밝은 필 + 어두운 글자 + 같은 아이콘
80+ 매우 좋음 60+ 양호 40+ 보통 20+ 주의 나쁨 – 평가값 없음

두 세트는 같은 파랑→적 순서이며, 어느 쪽에서도 숫자 + 등급명 + 등급 아이콘 세 겹으로 적습니다. 등급 아이콘은 순서가 형태로도 읽히도록 고정입니다 — 별(매우 좋음) · 체크(양호) · 이중선(보통) · 삼각 경고(주의) · 금지(나쁨) · 점선 원(평가값 없음). 색·아이콘 어느 하나만으로 판단을 전달하지 않고, 값이 없으면 –로 두며 0점으로 바꾸지 않습니다.

07 — 두 레이어를 섞는 규칙

  1. 글래스 히어로는 화면당 하나, 항상 최상단. 아래로 반복하면 위계가 사라집니다.
  2. 근거·표·폼·데이터 상태 칩은 항상 밝은 레이어에. 글래스 위에는 수치와 한 줄 문장까지만.
  3. 점수는 숫자 + 등급명 + 색 세 겹. 레이어에 따라 등급 팔레트 세트만 바꿉니다.
  4. 값이 없으면 –. 0점·정상·안전으로 치환하지 않습니다.
  5. AI가 만든 문장·추천에는 「AI 제안」 칩과 근거를 같은 카드 안에 둡니다.
  6. 경고·미연동 알림 면은 --pd-alert(#ffe9e9) 바학 + --pd-alert-ink 글자, 화면당 1~2개까지. 단순한 값 부재(no_data)는 경고가 아니므로 이 면을 쓰지 않습니다.
  7. 모션은 페이드·슬라이드 200ms 이내, prefers-reduced-motion에서 차단. backdrop-filter 미지원 시 유리면을 rgba(255,255,255,.22) 단색으로 폴백합니다.
  8. 그라디언트는 코발트 히어로 하나만. 밝은 레이어에는 그라디언트를 쓰지 않습니다.
