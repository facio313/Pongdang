# Handoff: Pongdang 홈 · 오늘 · 추천 · 지도 · 내 코스 (그룹 A/B 화면)

> **이번 작업(데스크탑 신규 · 모바일 명소 탭 추가)은 `구현 가이드 — 데스크탑 · 모바일.md`를 보세요.** 이 문서는 그 전제가 되는 토큰 · 등급 팔레트 · 데이터 표기 규칙 · 기존 모바일 화면 명세입니다.

## Overview
강릉 물놀이·물여행 서비스 「퐁당」의 모바일 화면 설계 핸드오프입니다. 기존 그룹 A(컨디션 데이터, A1~A8)를 하나의 디자인 시스템으로 정리하고, 신규 그룹 B(AI 추천·컨시어지, B1~B5)와 홈 화면을 추가했습니다. 하단 인디케이터는 **홈 · 오늘 · 추천 · 지도 · 내 코스** 5개이며 홈이 최우선 진입 화면입니다.

대상 저장소: `facio313/Pongdang` — `frontend/` (React + Vite + TypeScript).

## About the Design Files
이 번들의 `.dc.html` 파일들은 **HTML로 만든 디자인 레퍼런스**입니다. 의도한 레이아웃·색·타이포·인터랙션을 보여주는 프로토타입이며, 그대로 복사해 제품에 넣을 프로덕션 코드가 아닙니다.

할 일은 이 디자인을 **대상 코드베이스의 기존 환경(React + Vite + TS, `frontend/src/*Page.tsx` + 페이지별 CSS)으로 다시 구현**하는 것입니다. 기존 관례를 따르세요:
- 화면 1개 = `frontend/src/XxxPage.tsx` + `frontend/src/xxxPage.css`
- CSS는 **페이지 루트 클래스에 스코프**하고 `frontend/src/styles.css`는 수정하지 않습니다 (AGENTS.md의 그룹 A 관례, `waterIndexHub.css`·`waterForecast.css` 참고)
- 해시 라우트는 `frontend/src/App.tsx`의 `previewPages` 맵에 항목 추가
- 등급·색·NULL 처리는 **기존 `frontend/src/groupAGrade.ts`를 재사용** (새로 만들지 않음)
- 브랜치는 `dev`에서 생성하고 PR 대상도 `dev` (`main`은 CI 통과 후 자동 배포)
- 검증: `cd frontend && npm run lint && npm test && npm run build`

## Fidelity
**High-fidelity (hifi)** — 색·타이포·간격·상태 표기까지 확정된 시안입니다. 아래 디자인 토큰과 수치를 그대로 재현하세요. 단, 세 가지는 **의도적으로 비어 있는 슬롯**이며 별도 디자인 작업 대상입니다(점선 박스로 표시):
1. 홈 히어로의 파도·날씨 애니메이션 시각화
2. 홈/오늘의 시간대별 그래프(09–18시)
3. 지도 경로 렌더링(카카오 지도 위 경로 선)

## 데이터 표기 규칙 (반드시 유지 — AGENTS.md / W37 문서 규칙)
구현 시 가장 중요한 제약입니다. 디자인의 모든 칩·문구가 이 규칙에서 나왔습니다.
1. 점수는 항상 **숫자 + 등급명 + 등급 아이콘 + 색** 네 겹으로 표시. 색이나 아이콘 하나만으로 판단을 전달하지 않습니다.
2. 값이 없으면 `–`. **0점·정상·안전으로 치환 금지.** NULL·`unknown`·`missing`·`unavailable`은 안전 보증이 아닙니다.
3. 수집 미구현·미연동 데이터는 「예시 데이터」 / 「수집 미구현」 / 「no_data」 / 「partial」 칩을 붙입니다.
4. AI가 생성한 추천 문장에는 「AI 제안」 칩 + 근거(사용 지표·시각·출처)를 **같은 카드 안에** 붙입니다. 근거 없는 추천 카드는 만들지 않습니다.
5. 지표 막대는 **점수 기여도가 아니라 지표 값의 상대 위치**임을 화면에 명시합니다.
6. 점수 · 수온 · 안전 상태 · 신뢰도는 서로 다른 값이며 하나로 요약하지 않습니다. 신뢰도 색(`#4a6d8c`)은 등급 팔레트와 분리합니다.
7. 지점별로 저장된 값은 수영 점수와 수온뿐입니다. 날씨·파고·강수는 경포해변 예보 값이며 다른 지점의 실측값이 아님을 명시합니다(허브 화면 문구 그대로 유지).
8. 저장된 활동은 `수영 · 래프팅 · 휴식` 3종입니다. 서핑·SUP·갯벌 체험 등은 수집 항목이 아니므로 예시 표기 필수.

### 레이어 규칙
- **코발트 글래스 = 히어로 레이어**: 화면 최상단 1개만. 지금·여기(오늘 상태·지도·수치). 내부 카드는 `--pd-glass` + 흰 헤어라인. 수치는 Space Grotesk 700, 40px 이상. 본문 길이 텍스트 금지.
- **물안개 파스텔 = 본문 레이어**: 선택·근거·목록·폼. `--pd-mist` 배경 위 흰 카드, radius 18, 그림자 1단계. 데이터 상태 칩은 전부 이 레이어.
- 그라디언트는 코발트 히어로 하나만. 밝은 레이어에 그라디언트 금지.
- `backdrop-filter` 미지원 시 유리면을 `rgba(255,255,255,.22)` 단색으로 폴백.
