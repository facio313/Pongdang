## 남은 확인

- **HYD-03:** HTTP403/코드30. 사용자 전달의 심의 대기를 기록한다. 코드30만으로 실제 포털 심의 상태를 확정하지 않으며 승인 완료 후 현재 키 연결을 다시 확인한다.
- **TOUR-05:** 동일 소량 요청을 두 번 확인했으나 HTTP403/코드30. 영문·일문·간체는 같은 키로 성공했다. 번체 서비스의 신청·승인·연결 키·이용기간 확인이 필요하다. 미신청이라고 단정하지 않는다.
- **WQ-04:** 최초 25초 timeout 뒤 재시도에서 HTTP200/코드00/totalCount0. 2026-09-13 전체 조회와 2025-09-01 인천강화 정점 조회 모두 0건이었다. 인증 성공과 실제 수질관측 확보를 분리하며 전체 기간·모든 정점에 자료가 없다고 일반화하지 않는다.
- **WQ-06:** 정점 목록의 totalCount13 중 1행을 수신했다. 인천강화 정점코드·좌표를 확인했다. 관측소 목록이 수질관측값을 대신하지 않는다.
- **KMA-06:** 이번에는 관측소516의 AWS 최신 자동조회(tm2=0)를 확인했다. 시작·종료 표식과 관측1행이 있었으며 해양기상부이 등 API허브 전체를 이번에 재검증한 것은 아니다.

## 앱 연결 상태

현재 외부 수집 작업은 weather7·marine10·water4·places2의 23개다. 이번 신규 신청16종과 자외선은 아직 주기 작업에 없다. 기존 koem_catalog는 Nemo 정점이고 새 WQ-06의 Wemo 정점을 대신하지 않는다. API 키 접근이 성공해도 자동으로 저장되거나 현재 점수 계산에 사용되는 상태는 아니다.

승인된 API의 실제 자료를 사용하려면 해당 제공처 어댑터·정규화 계약·작업 등록·장소 매핑을 추가하고, 신규 지표를 조건 점수에 포함할 경우 API와 프론트의 지표 계약도 확장해야 한다. 이번 요청에서는 연결 여부를 검사하고 엑셀에 표시했으며 수집 코드를 추가하지 않았다.

## 기록 범위

총 HTTP 요청은 23회다. 요청당 pageNo1·numOfRows1 또는 단일 AWS 관측소로 제한했다. 예보·관측·통계의 실제 제공시각은 [JSON 보고서](api-recheck4-2026-09-14.json)에 보존했다. 조회 표본 수신은 전국 장소·전체 기간 가용성 또는 활동 적합도 검증을 뜻하지 않는다.

보고서에는 인증값과 인증이 포함된 URL, 원본 응답 전체를 저장하지 않았다. 최종 보고서에 기존 키의 원문·URL 인코딩 변형이 포함되지 않는지 검사했다. 엑셀 키 값은 변경하지 않으며 gitignore 대상이다. API 조회는 읽기 전용이며 운영/로컬 DB 저장·수집기 실행·배포는 하지 않았다.

엑셀에서는 API 신청표의 승인·인증 확인·메모·확인할 사항을 갱신하고 WQ-06을 추가한다. 신청자의 전달, 실제 응답, 자동 수집 연결 상태를 구분한다. 이전 실호출 보고서는 보존한다.
