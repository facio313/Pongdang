## AWS 상세 확인

- 최종 판정: **HTTP 200, 실제 1행 수신**.
- 실제 데이터 수신 성공
- 명시시각은 시작마커만 수신, 최신시각 자동조회로 실제 관측자료 수신 성공
- 공식 AWS2 응답 헤더의 WD1/WS1/TA 열명과 단위로 표본 해석. RE=-99.9는 결측 표식으로 보존하며 0으로 간주하지 않는다. 명시시각 조회 미완료의 정확한 기관 내부 원인은 미확인.
- 관측 표본: KST 202609132357, 관측소 516. 이는 해당 관측소 자료 수신 확인이며 전체 AWS 지점 검증은 아니다.
- 지정 시각 조회는 HTTP 200이지만 시작 표식만 반환했고, 최신 시각 자동 조회는 시작·종료 표식과 숫자 관측 행을 모두 반환했다. 과거 지정 시각 조회의 문제 원인은 아직 확정하지 않았다. 최신 관측 조회에는 실제 데이터 수신 근거가 있다.
