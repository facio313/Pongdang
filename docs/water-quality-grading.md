# 수질 1~5등급 표시

확인일: 2026-09-16. 적용 버전: `korean-marine-wqi.v1`.

## 채택한 기준

해수는 국내 생태기반 해수수질 WQI를 사용한다. 사용자가 요청한 방향과
동일하게 1등급이 가장 좋다. 자체 임의 점수나 수온으로 수질을 추정하지 않는다.

| 등급 | 표시 | 공식 WQI |
| --- | --- | --- |
| 1 | 매우 좋음 | 23 이하 |
| 2 | 좋음 | 24~33 |
| 3 | 보통 | 34~46 |
| 4 | 나쁨 | 47~59 |
| 5 | 아주 나쁨 | 60 이상 |

공식 기준: [해양환경정보포털 WQI](https://www.meis.go.kr/mei/wqi/introduce.do).
이 기준은 표층 DIN·DIP·클로로필 a, 투명도와 저층 산소포화도의 항목별
1~5점 및 해역별 기준값을 사용한다. WQI는 `10×DO + 3×(Chl-a+SD) + 2×(DIN+DIP)`로
20~100의 정수다. 표의 DO 등은 원 측정값이 아닌 항목별 점수다.

## 논문 검토와 선택 이유

- 노태근 외 (2012), **해역의 환경특성을 고려한 해양환경 기준설정과 수질등급 평가**,
  바다 17(2), 45–58.
  [논문 정보·초록](https://www.kci.go.kr/kciportal/ci/sereArticleSearch/ciSereArtiView.kci?sereArticleSearchBean.artiId=ART001762441).
  해역별 배경 특성을 반영한 평가체계의 근거를 확인했다.
- **2013–2017년 한국연안의 생태기반 해수수질 평가 결과** (2019).
  [원문](https://www.jkosmee.or.kr/_PR/view/?aidx=18375&bidx=1417).
  국내 정기 관측망에 같은 5등급 기준을 적용한 연구다. 서로 다른 해역의 농도를
  하나의 임의 임계값으로 재평가하는 것보다 기존 공식 등급을 보존하는 것이 적합하다.
- [해양환경공단 API 변경 공지](https://www.data.go.kr/bbs/ntc/selectNotice.do?originId=NOTICE_0000000003135)는
  실제 사용 중인 API의 `eclgyZoneAreaGrad`, `eclgyZoneAreaScore` 제공을 명시한다.

## 읽기·산정 규칙

`GET /api/data/quality/grade?spot_id=…`는 기존 수집 DB만 읽는다. 수집·시드·외부
API 요청·장소 매핑을 쓰지 않는다. 비교·후기 분석 API와 독립적으로 검사 이력을 읽는다.

1. 직접 연결된 해양 수질 관측소를 우선한다. 없으면 분류된 해수욕장에 한해
   10km 안에서 수집 이력이 있는 가장 가까운 관측소를 선택한다. 등급을 보기 전에
   관측소를 정하므로 더 좋은 등급을 찾아 대체하지 않는다. 거리는 참고 검색 범위이지
   해수욕장의 대표성 입증 기준이 아니다.
2. 최신 정정본을 먼저 선택한 뒤 가장 최근 검사일의 자료를 읽는다. 이전의 좋은
   값으로 최신 결측·충돌을 가리지 않는다. 각 읽기는 101건까지 확인해 100건 초과면
   거절한다. 표층·저층에 반복된 동일 공식 등급은 하나로 표시하고 서로 다르면 보류한다.
3. 유효한 공식 등급을 우선 사용한다. 등급 없이 공식 WQI만 있으면 위 표로 분류한다.
   정수 20~100 외 지수, 1~5 외 등급, 지수와 등급 불일치는 보류한다.
4. 검사 유효기간을 늘리지 않는다. 과거 검사도 `historical`로 반환하되 UI는 등급 옆에
   **과거**를 표시하고 검사일·경과일·관측소·거리를 함께 보여준다. 현재 해변 등급과
   안전 상태는 각각 `null`, `unknown`이다.
5. 농도 단위가 없는 측정값은 단위를 추정하지 않는다. 현재 수집 계약에는 WQI 재계산에
   필요한 투명도·저층 산소포화도와 검증된 단위가 모두 갖춰져 있지 않아 원 농도를
   조합한 재계산은 하지 않는다. 공식 제공 WQI를 사용하면 이 추정이 불필요하다.
6. 하천·계곡에 해양 WQI를 적용하지 않는다. 담수 등급은 별도 기준·단위 확인이 필요하다.

## 입수 안전과의 관계

[WHO 2021 수영용수 지침](https://www.who.int/publications/i/item/9789240031302)은
보건 위해 관리, 미생물 검사와 현장 위험평가를 다룬다. WQI는 해양 생태·부영양화 지수로,
대장균·장구균 검사나 해수욕장 통제를 대체하지 않는다. 해당 구분은 UI의 수질 설명과
기준 펼치기에 표시한다.

## 검증

경계값 23/24, 33/34, 46/47, 59/60; 범위 외 값·소수·결측·충돌;
관측소 거리·담수 제외; 최신 결측의 과거 등급 대체 금지; 제공기관 정정;
GET 전후 DB 무변경; 실제 API 계약을 통한 홈·오늘 화면의 등급·검사일 표시를 검증한다.
