### 등급 구간 (화면 표시용, DB 저장 기준 아님)

| 점수 | 등급 | 색 |
| --- | --- | --- |
| 80–100 | 매우 좋음 | `#1d4ed8` |
| 60–79 | 양호 | `#0891b2` |
| 40–59 | 보통 | `#a16207` |
| 20–39 | 주의 | `#c2410c` |
| 0–19 | 나쁨 | `#b91c1c` |
| NULL | 평가값 없음 | `#5b6673` |

적록 대비 대신 파랑→적 순서를 써서 색각 이상에서도 순서가 읽힙니다.
색만으로 구분하지 않고 항상 숫자 + 등급명을 함께 표기합니다.

### ⚠️ 검증 필요

- **`score` 스케일**: 더미는 `score=None` 고정이고 산출식은 Multtara collector 소유라
  이 저장소에서 0~100인지 0~1인지 확인할 수 없습니다. `waterIndexGrade.ts`의
  `SCORE_MAX`를 100으로 두었으니, 실제 cksDB 값 확인 후 이 상수만 고치면 됩니다.
- **`spots.region` 실제 값**: `q=강릉` ILIKE 검색으로 거릅니다. 실제 저장된 지역
  문자열이 다르면 `강릉만 보기`를 해제해야 장소가 보입니다. 화면에 안내가 있습니다.

### 이번 주 범위에서 뺀 것 (후속)

- 다중 열 동시 필터: 현재 백엔드 `/datasets/{key}`는 `filter_column` 한 개만 받습니다.
  → A1 후속 이슈로 분리.
- 장소 100곳 초과 대응: 페이지 상한이 100행입니다. 강릉 범위에서는 당분간 충분합니다.
- 근거 지표는 평가 시점이 아니라 **최신 관측**입니다. 점수 계산에 실제로 쓰인 값과
  같다는 보장이 없어 화면에 그대로 적었습니다. 정확한 근거 연결은 `lineage` 활용 검토 필요.
- 점수 추이 차트: 후속 범위. 실제 타일 지도 연동 방식은 A1 통합 지도 내에서 별도 검토 필요.
- (후속 아이디어) 지도 핀 위에 점수 구간별 이미지 리소스를 지정해 노출하고, 작은 애니메이션을 추가하는 방안 — 지금은 D안(원형 게이지+온도계)까지만 확정, 이미지/애니메이션은 다음 라운드 검토.
