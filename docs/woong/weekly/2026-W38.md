## B1. AI 여행 추천 (페르소나 큐레이션)

사용자 취향을 학습·유형화하여 장소를 추천합니다.

- **수집 데이터**: 방문 기록, 찜 목록, 리뷰, 선호 지역
- **취향 수집 UI**
  - 스와이프 UI: '잔잔한 인피니티풀' vs '파도치는 서핑 해변' 이미지 카드 스와이프
  - 태그 큐레이션: `#아이와함께_얕은물`, `#튜브타기좋은_유속`, `#인생샷_온천`, `#한적한_계곡`
- **페르소나 예시**
  - 온천 힐러형 (조용·힐링) → 덕구온천, 수안보온천
  - 서퍼형 (액티비티) → 양양, 제주
  - 계곡 탐험가형 (자연·인파 회피) → 깊은 산속 계곡

### 투두

- [ ] 페르소나 정의표 확정 (유형 · 판별 기준 · 대표 장소)
- [ ] 태그 사전 확정 (`#아이와함께_얕은물` 외, 장소 매핑 규칙 포함)
- [ ] 스와이프 카드 UI 구현 (키보드 대체 조작 포함)
- [ ] 태그 큐레이션 UI 구현
- [ ] 취향 → 페르소나 판별 로직 및 단위 테스트

## B2. AI 일정 자동 생성

- **입력**: 출발지, 이동 수단, 당일치기 여부, 여행 인원, 예산
- **출력 예시**

  ```
  08:00 출발 → 10:00 계곡 도착 → 12:00 인근 맛집
  → 14:00 카페 → 18:00 일몰 명소 → 20:00 귀가
  ```

### 투두

- [ ] 입력 폼 화면 구성 (출발지 · 이동 수단 · 당일치기 · 인원 · 예산)

- [ ] 이동 시간 산출 방식 결정 (⚠️ 아래 검증 필요 참고)

## B3. AI Water Concierge — 자연어 추천

사용자가 여행 계획을 말로 설명하면 AI가 최적의 물 여행지를 추천합니다.

- **입력 예시**: "이번 주말에 연인과 드라이브하면서 물 보러 가고 싶어"
- **출력 예시**

  ```
  1위 강릉 안목해변 / 2위 춘천 의암호 / 3위 속초 영랑호
  추천 이유: 혼잡도 낮음 · 일몰 전망 우수 · 현재 Water Index 높음
  ```

### 투두

- [ ] 자연어 입력 → 구조화 조건(지역·동행·활동·시점) 파싱 설계
- [ ] 순위 카드 · 추천 근거 화면 구성
- [ ] 추천 근거를 A1 Water Index 값과 연결 (수집 미구현 항목은 근거에서 제외)

## B4. AI Water Companion — 실시간 여행 동행

여행 중 실시간으로 조언을 주는 AI 동반자.

- **예시 멘트**
  - "현재 출발하면 일몰 15분 전에 도착 가능합니다."
  - "오늘은 파고가 높아 수영보다 산책을 추천합니다."
  - "30분 후 간조가 시작됩니다."
  - "현재 계곡 수위 상승이 감지되었습니다."
- **가치**: 단순 추천을 넘어 실시간 여행 동반자 역할 (안전 레이더와 직결)

### 투두

- [ ] 알림 카드 · 여행 중 화면 와이어프레임
- [ ] 멘트 유형별 근거 데이터 매핑 (일몰 / 파고 / 물때 / 수위)
- [ ] 안전 관련 멘트의 표현 기준 정의 (관측 없음 → 안전 보증 문구 금지)

## B5. Mood Based Water Travel — 감정 기반 추천

사용자의 감정 상태를 기반으로 여행지를 추천합니다.

- **예시**
  - "요즘 너무 지친다" → 힐링형(온천·호수·물멍 명소)
  - "답답하고 스트레스가 많다" → 해소형(폭포·서핑 해변·계곡)
- **가치**: 관광 추천을 넘어 감정 기반 여행 서비스로 포지셔닝

### 투두

- [ ] 감정 → 장소 유형 매핑표
- [ ] 감정 선택 UI (B3 자연어 입력과 엔진 공유)

## 원칙 확인 (AGENTS.md)

- 읽기 전용 뷰어를 유지하고 수집기를 실행하거나 외부 API를 호출하지 않습니다.
- `missing` · `unknown` · `unavailable` · NULL을 실시간 관측이나 안전 보증으로 표시하지 않습니다.
- 더미 데이터는 `pongdang_demo` 스키마에만 있고 실제 데이터의 빈칸을 대체하지 않습니다.
- 새 조회 열이 필요하면 `backend/app/collector_catalog.json`과 DB 열 권한을 함께 검토합니다.
- PR 대상 브랜치는 `dev`이며, `main`은 CI 통과 후 자동 배포됩니다.
